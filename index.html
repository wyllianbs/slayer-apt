Slayer Editor — APT repository

Signed APT repository for the Slayer Editor, a lightweight Qt 6 code editor with an embedded terminal.

Install

Add the signing key and the repository (Debian/Ubuntu, amd64):

curl -fsSL https://wyllianbs.github.io/slayer-apt/slayer-editor.gpg.asc \
  | sudo gpg --dearmor -o /usr/share/keyrings/slayer-editor.gpg

echo "deb [signed-by=/usr/share/keyrings/slayer-editor.gpg] \
https://wyllianbs.github.io/slayer-apt stable main" \
  | sudo tee /etc/apt/sources.list.d/slayer-editor.list

sudo apt update
sudo apt install slayer-editor

Verify the signing key
